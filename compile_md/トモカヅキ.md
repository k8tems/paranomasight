# トモカヅキ

――これは むかしむかしの 志摩国の海での お話。
とある島の小さな村に 泳ぎが自慢の 海女の娘がおったそうな。

その日は 強い風が吹き荒れ いつもより波が高かった。
泳ぎが得意な娘は 恐れることなく 荒れた海に入っていくが
どうしたことか アワビはおろか 小さな貝ひとつ見つからぬ。

そこで さらに深く潜ってみたところ 娘はふと気配を感じ
背後を振り返る。どうにも あの暗い岩陰から 誰ぞ こちらを
見ている気がしてならぬ。訝しく思いながら 近づいてみると
なんとそこには 娘と瓜二つの姿をした 海女がいるではないか。

娘が唖然としていると その海女は 見たこともないような
大きなアワビを 差し出してくる。娘は ごくりと唾を呑む。
ああ どうしても そのアワビが欲しくてたまらぬと
手を伸ばさずには いられなかった。

あともう少し……そう思った瞬間 その海女の手がにゅっと伸び
娘の腕をいきなり掴む。ぎょっとして 娘は必死に もがいたが
時すでに遅く 引きずり込まれるように 海の底へと沈んでいって
しまったそうな。

いつしかそれは 自分と同じ姿で海中に並ぶ姿から 《共潜き》 と
呼ばれるようになり もし 海の中で出会っても 決して 差し出された
ものを受けとってはならぬと 言い伝えられるようになった。

今でも 《トモカヅキ》 と呼ばれるその妖怪を 海女たちは
震え上がるほど恐れており 海に入る時は 《セーマン・ドーマン》 を
魔除けとして 身に着けるようになったという。
